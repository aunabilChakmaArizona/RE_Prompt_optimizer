OPENBOOKQA FIRST-STAGE PROMPT OPTIMIZATION STATUS (LAMBDA = 1)
================================================================

Scope
-----
Dataset: OpenBookQA
Target models: Qwen3-4B and Gemma3-4B
Modes: reasoning and non-reasoning
First-stage optimizers: RPO, EvoPrompt-DE, and ETGPO
Validation: 900 questions, split into three fixed folds of 300
Selection: stable accuracy = mean fold accuracy - 1.0 * population fold standard deviation
Test evaluation: not run; every score below is a validation score

Status rule
-----------
READY means that the run uses the current implementation, the selected prompt differs
from the initial prompt, and its stable validation score is higher than the baseline.
NOT READY means that the completed run retained the baseline or failed to improve it.
PENDING RERUN means that historical output exists but cannot be used as a current result.
