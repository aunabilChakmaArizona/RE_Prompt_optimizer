Validation stable scores versus the recorded final test
======================================================
All scores are percentages; gains are percentage points (pp).
Validation stable = mean fold accuracy - lambda * population fold std.
Every listed run uses lambda=1. Validation N is total across three folds.
First-stage gains compare with that optimizer run's original initial prompt.
Second-stage gains compare with its own recorded source-prompt validation;
do not subtract first-stage scores from another validation size or run.
Test gains compare the same selected parent/child prompts on the 500-question test.
These test scores are the OLD 10-token batch, not the new matched16 retest.
Gemma first-stage test gains are N/A because its batched initial score is anomalous.
All other Gemma test comparisons are provisional pending matched-setting checks.
No test stable score is calculated, and no results are selected using test scores.
