Compatibility and remaining work
--------------------------------
- This is a controlled upgrade, not the latest vLLM release.
- Let vLLM resolve its matching PyTorch dependencies (expected torch 2.8.0).
  Do not independently upgrade torch or use the old requirements_vllm.txt.
- Optional project packages above are not fully pinned; pip check verifies
  dependency consistency, not GPU runtime compatibility or exact reproduction.
- Server NVIDIA driver observed on 2026-09-16: 550.163.01. This default wheel
  uses CUDA 12.8. Recommend an administrator-approved driver upgrade to 570.26
  or newer before model runs; older-driver PTX/JIT compatibility is not assured.
  Conda/pip installation does not upgrade the system driver.
- Leave the existing environment and currently running experiments untouched.
- The project model loader now accepts vllm==0.8.5.post1 and vllm==0.11.0.
  requirements_vllm_v2.txt describes the new environment; old pins are unchanged.
- Forward-only loss/fluency scoring is implemented as the explicit option
  --backend dual --objective-scoring-backend vllm. The Qwen Math tuning script
  enables it. HF still computes gradients. Synthetic parity tests pass;
  small Qwen/MATH GPU comparisons are now documented in
  experiment_tracking/second_stage/length_sorted_objective_scoring_benchmark.txt.
  Gemma, full-beam timing, and near-tie score reproducibility remain open.
