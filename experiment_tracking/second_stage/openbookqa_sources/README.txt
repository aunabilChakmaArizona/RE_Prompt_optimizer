Portable latest OpenBookQA RPO source prompts
==============================================

These files are Git-trackable copies of the four latest RPO source prompts
used for the Qwen and Gemma OpenBookQA second-stage experiments. They avoid
depending on ignored first-stage artifacts under `outputs/` on remote servers.

- qwen/rpo5_latest.txt: retained actual RPO iteration 1.
- qwen/rpo10_latest.txt: retained actual RPO iteration 9.
- gemma/rpo5_latest.txt: experimental RPO-5 from actual iteration 1.
- gemma/rpo10_latest.txt: experimental RPO-10 from actual iteration 2.
